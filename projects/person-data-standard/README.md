# Person Data Standard

The Person Data Standard defines a common, shared understanding of the data required to describe a person in digital services and information exchanges. It is intended to help teams align on terminology, capture the right attributes, and model the relationships between people and the organisations, services and contexts that interact with them.

This work is still in progress. It is being developed as an open, collaborative reference for policy, design and delivery teams so that person-related data can be described consistently across systems and use cases.

## What the Person Data Standard is

The standard brings together:

- the core attributes used to describe a person
- the conceptual relationships between those attributes
- a logical structure for person data in a reusable model
- example scenarios showing how the model is applied in practice

In simple terms, it is a shared data definition and modelling resource for person data. It helps reduce ambiguity, supports interoperability, and provides a common starting point for future implementation work.

## What is in this folder

This folder contains the working materials for the Person Data Standard and is organised by topic.

- `attribute-definitions/`
  - contains the specification for person attributes, including the current tranche of agreed definitions and supporting documentation.
- `models/`
  - `domain-model/`
    - captures the core conceptual model of the person domain, including the domain model description, CSV/TTL exports and illustrative diagram views.
  - `logical-model/`
    - sets out the structured logical model for person data, including entities, structures and linked model representations.
- `use-cases/`
  - contains example use cases and scenario materials showing how the person data model can be applied in service and business contexts.

## How users can browse the material

A sensible way to explore the standard is:

1. Start with `attribute-definitions/` to understand the person attributes being described.
2. Review `models/domain-model/` to see the foundational concepts and relationships.
3. Move to `models/logical-model/` to inspect the structured data model.
4. Read the materials in `use-cases/` to understand real-world applications and scenarios.

This folder is intended to act as a central entry point for the standard and a starting place for anyone wanting to understand, review or build on the Person Data Standard.
