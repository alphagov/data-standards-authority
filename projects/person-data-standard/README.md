# Introduction
This folder serves as the working area for the Person Data Standard.

The Person Data Standard forms part of a significant cross-Government effort led by the Data Standards Authority to establish shared, reusable data standards that underpin a wide range of Government services and policy outcomes.

It has been developed collaboratively through the Domain Expert Group on Person, with contributions from experts across multiple Departments and bodies. 


## What is in this folder

This folder contains the working materials for the Person Data Standard and is organised by topic.

- `attribute-definitions/`
  - contains the specification for person attributes, including the current tranche of agreed definitions and supporting documentation.
- `models/`
  - `domain-model/`
    - captures the core domain model of the Person domain CSV/TTL exports and illustrative diagram views.
  - `logical-model/`
    - sets out the structured logical model for Person data, including entities, structures and relationships.
- `use-cases/`
  - contains example use cases and scenario materials showing how the person data model can be applied in service and business contexts.

## Where to Start

Users new may find it useful to start with:
 - [attribute-definitions/attributes-specification-for-person.docx](./attribute-definitions/attributes-specification-for-person.docx): A document containing specifications for the "core" attributes of a Person
 - [models/domain-model/domain-model.md](./models/domain-model/domain-model.md): The Domain Model, the approach by which the Person Domain has been broken down into different categories and attributes.

## Making Changes

This standard is still continuously being developed and iterated by the Domain Expert Group on Person.
Specific feedback can be raised as issues under the relevant issue in the GitHub.

For more complex feedback and discussions, please contact data-standards-authority@dsit.gov.uk
